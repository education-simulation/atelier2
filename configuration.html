6. Ton projet dans Antigravity

1 Copie d'abord ce message : il contient les règles de ton projet.

Prépare ce projet pour mes simulations. Ne fais rien d'autre. 1. Crée, à la racine du dossier de ce projet, un fichier AGENTS.md qui contient, en français, toutes les règles ci-dessous : elles doivent s'appliquer à toutes les conversations de ce projet. 2. Si Antigravity lit aussi les règles d'un espace de travail dans un autre dossier (par exemple .agent/rules/ ou .gemini/), crée-y aussi un fichier qui dit simplement de suivre AGENTS.md. Les règles des simulations : - chaque simulation est un seul fichier HTML, en français, sans aucune ressource externe ; - enregistre chaque simulation directement dans le dossier de ce projet, sans sous-dossier, avec un nom de fichier court et parlant, sans espace ni accent, par exemple « titrage.html ». Si un fichier de ce nom existe déjà pour une autre simulation, ne l'écrase jamais : choisis un autre nom (par exemple « titrage-2.html »). Pour une modification, garde le même fichier ; - tout en haut du fichier, juste après <!DOCTYPE html>, mets ce commentaire, avec le vrai nom du dossier du projet et la vraie adresse complète du fichier, et garde-le à jour à chaque modification : <!-- Ceci est le CODE de la simulation : ne la regarde pas ici. Pour la voir, ouvre le dossier « nom du dossier du projet » et double-clique sur ce fichier, ou copie cette adresse dans la barre d'adresse de ton navigateur (Chrome, Firefox, Safari, Edge) : file:///chemin/complet/du/fichier.html --> ; - quand une simulation est prête (création ou modification), réponds seulement par ces deux parties, avec les vrais noms du dossier du projet et du fichier et le vrai chemin complet du fichier. Garde la partie ② EN DEHORS de l'encadré, avec l'adresse seule dans un vrai bloc de code, pour qu'elle ait son bouton de copie : > [!TIP] > ✅ **Ta simulation est prête.** > > **① Ton code, dans Antigravity :** [nom du fichier.html](file:///chemin/complet/du/fichier.html) **② Le rendu de ton code, dans ton navigateur :** ouvre le dossier de ton projet « nom du dossier du projet », puis **double-clique sur le fichier** nom du fichier.html (Chrome, Firefox, Safari, Edge), ou copie cette adresse (bouton de copie à droite) et colle-la dans la barre d'adresse de ton navigateur : ```text file:///chemin/complet/du/fichier.html ``` *S'il est déjà ouvert, recharge la page.* Quand AGENTS.md est créé, réponds seulement par cet encadré : > [!TIP] > ✅ **Ton projet est configuré.** Ses règles sont dans AGENTS.md : elles valent pour toutes les conversations de ce projet. > > 👉 **Choisis ton atelier :** https://atelier2.rasf.fr/ateliers.html?ou=dans

2 Crée ton projet : dans le menu de gauche, à droite de « Projects », clique sur l'icône du dossier avec un +, puis choisis le dossier de ton projet.

7. Ton projet est prêt

L'IA écrit le fichier AGENTS.md dans le dossier de ton projet : les règles de toutes les conversations de ce projet. Elle te demandera peut-être une autorisation (« Allow… ? ») : choisis Yes, and always allow.

Elle répond par l'encadré vert « ✅ Ton projet est configuré ». Place à la simulation !
