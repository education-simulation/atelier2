🚀 Ouvre l'atelier dans Antigravity

Les ateliers se font dans Antigravity. Ton projet est déjà configuré ? Il suffit d'ouvrir cette page dans Antigravity :

  1. Copie ce message :
    Sans rien lancer, réponds seulement par cet encadré, rien d'autre : > [!IMPORTANT] > 👉 **Clique sur ce lien pour ouvrir l'atelier :** https://atelier2.rasf.fr/ateliers.html?ou=dans

  2. Antigravity s'ouvre (si ton navigateur demande d'ouvrir Antigravity, accepte) : clique sur « + New Conversation », en haut à gauche.
  3. Colle le message (Cmd + V sur Mac, Ctrl + V sur Windows), puis Entrée.
  4. Clique sur le lien de sa réponse : cette page s'ouvre dans Antigravity, et tu choisis ton atelier.

Antigravity n'est pas encore configuré ? Configure-le d'abord. Pas encore installé ? Installe-le.
