# atelier

L'atelier « Je crée une simulation sur une page html avec l'IA », version 2 (Antigravity Projects), servie sur **https://atelier2.rasf.fr**. La version stable reste sur https://atelier.rasf.fr (dépôt education-simulation/atelier).

- `index.html` : le choix de l'IA (Antigravity seulement pour l'instant).
- `antigravity.html` : configurer Antigravity (message à coller) ou « déjà configuré » (bientôt).
- `configuration.html` : la page de configuration d'Antigravity, ouverte depuis Antigravity ; `decouvrir.html` et `fenetres.html` sont ses fenêtres d'aide.
